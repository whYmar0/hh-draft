# UniTalent (CampusCareer) — Платформа студенческого рекрутинга

> **MVP веб-платформы рекрутинга для студентов, выпускников и работодателей с фокусом на академический бэкграунд, исследовательские достижения и ранний старт карьеры.**

---

## 1. Описание продукта

**UniTalent** решает ключевую проблему рынка труда начального уровня: классические площадки (HeadHunter, LinkedIn, SuperJob) оптимизированы под кандидатов с опытом работы от 1–3 лет и не учитывают специфику студенческого резюме. 

На UniTalent ключевыми критериями отбора становятся:
* **Академический профиль:** ВУЗ, факультет, направление подготовки, курс, плановый год выпуска, средний балл (GPA с нормализацией шкал 4.0 / 5.0).
* **Практический и научный бэкграунд:** курсовые и дипломные проекты, публикации, участие в олимпиадах, хакатонах, кейс-чемпионатах, ссылки на репозитории (GitHub/GitLab) и научные статьи.
* **Специализированные фильтры работодателей:** подбор кандидатов по минимальному GPA, конкретным кафедрам/факультетам, курсам и стеку технологий без требования «опыта работы от года».
* **Прозрачный пайплайн отбора:** Kanban-воронка откликов (`Новый` → `Скрининг` → `Тестовое` → `Интервью` → `Оффер` / `Отказ`) с фиксацией обратной связи.

## 2. Архитектура и стек технологий

| Слой | Технологический стек | Назначение |
| :--- | :--- | :--- |
| **Frontend** | **Next.js 15 (App Router, TypeScript)** | SSR/SSG, серверные компоненты (RSC), высокая производительность |
| **Стилизация** | **Tailwind CSS + shadcn/ui** | Дизайн-система, адаптивная верстка (Mobile First), темная/светлая темы |
| **Иконки** | **Lucide Icons** | Консистентная и легковесная векторная графика |
| **Backend** | **Next.js Server Actions & Route Handlers** | Типобезопасная бизнес-логика, минимизация бойлерплейта |
| **Валидация** | **Zod** | Единые схемы валидации для форм, API и серверных действий |
| **База данных** | **PostgreSQL (v16)** | Реляционная целостность, поддержка сложных связей и фильтров |
| **ORM** | **Prisma ORM** | Типобезопасный доступ к данным, миграции и сидирование |
| **Аутентификация**| **NextAuth.js (Auth.js v5)** | Ролевая модель (RBAC: `STUDENT`, `EMPLOYER`, `ADMIN`), сессии JWT/DB |
| **Тестирование** | **Vitest + React Testing Library + Playwright** | Модульные, интеграционные тесты и E2E сценарии |
| **Контейнеризация**| **Docker & Docker Compose** | Локальная среда СУБД PostgreSQL и pgAdmin |

## 3. Требования к окружению

Перед запуском проекта убедитесь, что на вашей машине установлены:
* **Node.js** версии `>= 20.x` (рекомендуется LTS 20 или 22+)
* **npm** версии `>= 10.x` (или `pnpm` / `yarn`)
* **Docker Desktop** или **Docker Engine** с поддержкой **Docker Compose**
* **Git**

## 4. Быстрый старт и локальное развертывание

### Шаг 1. Клонирование репозитория и установка зависимостей
```bash
# Клонирование репозитория
git clone <repository-url> hh-draft
cd hh-draft

# Установка зависимостей проекта
npm install
```

### Шаг 2. Настройка переменных окружения
Скопируйте файл с примером конфигурации:
```bash
cp .env.example .env
```
Отредактируйте `.env` при необходимости (по умолчанию параметры настроены для работы с локальным Docker Compose).

### Шаг 3. Запуск инфраструктуры базы данных (Docker Compose)
Запустите контейнер PostgreSQL в фоновом режиме:
```bash
docker-compose up -d
```
Для проверки статуса контейнера:
```bash
docker-compose ps
```
Контейнер PostgreSQL будет доступен на порту `localhost:5432`. При необходимости можно включить pgAdmin на порту `localhost:5050` (раскомментировав соответствующий сервис в `docker-compose.yml`).

### Шаг 4. Применение миграций и сидирование тестовых данных
Выполните генерацию Prisma Client, применение миграций к БД и наполнение базы стартовыми справочниками (ВУЗы, специальности, демо-пользователи, тестовые вакансии):
```bash
# Генерация типов Prisma Client
npx prisma generate

# Применение миграций схемы
npx prisma migrate dev --name init

# Запуск сида тестовых данных
npm run db:seed
# или: npx prisma db seed
```

### Шаг 5. Запуск сервера разработки
Запустите локальный сервер Next.js:
```bash
npm run dev
```
Приложение откроется по адресу: [http://localhost:3000](http://localhost:3000).

## 5. Доступные скрипты `package.json`

| Скрипт | Описание |
| :--- | :--- |
| `npm run dev` | Запуск локального сервера разработки с Fast Refresh |
| `npm run build` | Сборка оптимизированного production-бандла |
| `npm run start` | Запуск собранного production-приложения |
| `npm run lint` | Запуск проверки линтером ESLint |
| `npm run test` | Запуск модульных и интеграционных тестов через Vitest |
| `npm run test:watch` | Запуск Vitest в интерактивном режиме отслеживания файлов |
| `npm run test:coverage` | Сборка отчета покрытия тестами |
| `npm run test:e2e` | Запуск сквозных E2E тестов через Playwright |
| `npm run prisma:generate` | Генерация Prisma Client из схемы `prisma/schema.prisma` |
| `npm run prisma:migrate` | Применение миграций схемы базы данных |
| `npm run prisma:studio` | Интерактивный UI для инспекции базы данных Prisma Studio |
| `npm run db:seed` | Запуск сидирования базы данных тестовыми фикстурами |
